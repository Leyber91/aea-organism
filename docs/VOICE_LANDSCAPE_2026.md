RESEARCH VERDICT — free natural TTS on an EDR-locked Windows laptop, Feb-Jul 2026 landscape (all claims checked against primary docs; inference flagged where present).

## Landscape changes since early 2026 (verified)

- Groq killed `playai-tts` (deprecation email 2025-12-23) and replaced it with Canopy Labs Orpheus: `canopylabs/orpheus-v1-english` + `canopylabs/orpheus-arabic-saudi` at `https://api.groq.com/openai/v1/audio/speech` (WAV default). Free-tier limits on the rate-limits doc: **10 RPM / 100 RPD**.
- Pollinations `openai-audio` is effectively dead as a free path: legacy `text.pollinations.ai` returns 404; the new `gen.pollinations.ai` `/v1/audio/speech` requires an `sk_` key and bills Pollen — GitHub issue #6194 (marked Done, no fix explanation) confirms 403 "Insufficient pollen" even on keys with the "daily pollen" grant. Do not build on it.
- Chatterbox family expanded: **Turbo** (350M EN, Dec 2025, distilled 10-step→1-step decoder, explicit `device="cpu"` support), **Multilingual v3** (500M, 23+ langs incl. Spanish, 2026-06-10), **Nano** (110M EN, HF repo updated 2026-07-06, gated; Resemble claims 3x realtime on CPU). All MIT, `pip install chatterbox-tts` (0.1.7, 2026-03-26), repo is 100% Python on torch/torchaudio.
- Kokoro: **no v2 exists.** Model last updated Apr 2025; still the 82M Apache model. espeak-ng is only "English OOD fallback and some non-English languages" — pip install is native-binary-free if you skip the espeak system installer.
- New heavyweights (Qwen3-TTS-12Hz 1.9B Jan 2026, VoxCPM2 2.3B Apr 2026, higgs-tts-3-4b, MOSS-TTS) are torch/safetensors but GPU-class — not laptop-CPU interactive.
- Windows OS-signed path: **still closed.** Windows AI Foundry / Microsoft.Windows.AI APIs list Phi Silica, imaging, OCR — no speech synthesis. WebView2 confirmed to NOT expose the "Online (Natural)" voices (WebView2Feedback #2660, unresolved). Narrator natural voices remain app-locked; nothing new replaces NaturalVoiceSAPIAdapter.
- edge-tts (pip): the Jan 2026 403 wave was fixed; current 7.2.8 (2026-03-22), no open 403 issues Apr-Jul 2026 (only #473 "intermittent no audio"). This removes the "needs Edge browser" limitation of your known-good voices.

## Ranked options

**1. edge-tts 7.2.8 (pip) — cloud, free, no key.** Same Azure neural voices as Edge read-aloud (`en-US-AndrewMultilingualNeural`, `en-US-AvaMultilingualNeural`, `es-ES-*`). EDR verdict: SURVIVES with one caveat — deps (aiohttp/multidict/yarl/frozenlist) ship C-extension .pyds; if EDR revokes them like it did onnxruntime, reinstall pure-Python: `set AIOHTTP_NO_EXTENSIONS=1` (+ `MULTIDICT_NO_EXTENSIONS=1 YARL_NO_EXTENSIONS=1 FROZENLIST_NO_EXTENSIONS=1`) then `pip install --no-binary :all: aiohttp multidict yarl frozenlist edge-tts`. Offline: NO. Integration: `python -m edge_tts --voice en-US-AndrewMultilingualNeural --text "..." --write-media out.mp3`, play WAV via stdlib `winsound` or PowerShell MediaPlayer. Privacy: undocumented consumer endpoint, no terms — nothing sensitive. Reliability risk: Microsoft has broken it before (Sec-MS-GEC DRM); it recovers, but pin a fallback.

**2. Kokoro-82M (torch) — local incumbent, still the CPU-realtime king.** No newer version; nothing at its size beat it in the window. EDR verdict: SURVIVES (pure pip on your already-working torch; skip the espeak-ng Windows installer — dictionary G2P covers normal English, rare OOD words degrade slightly). Offline: YES. Integration: `pip install kokoro>=0.9.4 soundfile`, `KPipeline(lang_code='a')`, voice `af_heart`. This is your privacy-safe default.

**3. Chatterbox Turbo / Nano (torch, MIT) — the material local upgrade if CPU speed proves out.** Clearly more natural/expressive than Kokoro (paralinguistic tags, cloning); Turbo's 1-step decoder targets low compute, Nano (110M) claims 3x realtime CPU — claim is Resemble's, unverified on your hardware; benchmark before adopting. Nano is HF-gated (your Leyber91 login) and newer than pypi 0.1.7, so expect `pip install git+https://github.com/resemble-ai/chatterbox`. EDR verdict: SURVIVES (100% Python on torch). Offline: YES. Multilingual v3 (500M) adds Spanish if that becomes load-bearing.

**4. Groq Orpheus — best free-tier cloud API quality.** `POST https://api.groq.com/openai/v1/audio/speech {"model":"canopylabs/orpheus-v1-english","input":...,"voice":...}` — free key, no card, 10 RPM / 100 RPD. EDR verdict: SURVIVES (plain HTTPS, `requests`). Offline: NO. Privacy: documented — inputs/outputs not used for training, logs ≤30 days, ZDR toggle (console.groq.com/docs/your-data). Best privacy stance of the cloud options.

**5. NVIDIA NIM (key already in your `NVIDIA_API_KEY`) — Chatterbox-Multilingual and Magpie-TTS hosted at build.nvidia.com,** 40 RPM, plain HTTPS. Caveat: 2026 reporting says hosted endpoints draw from the 1,000-5,000 signup credit pool — check your remaining credits before depending on it.

**6. Gemini TTS (`gemini-2.5-flash-preview-tts`) — free, no card, genuinely natural, but** free-tier limits are no longer published (AI Studio console only; preview models "more restricted") and free-tier prompts are used for training. Backup only.

**Rejected:** Pollinations audio (pollen-gated, legacy 404 — see above); ElevenLabs free (10k credits ≈ 10 min/mo, attribution required, API-tier terms murky); F5-TTS (no material 2026 update, flow-matching too slow for CPU interactive, base checkpoint non-commercial-trained-data caveat); the entire ONNX family — Piper, KittenTTS, Supertonic-3, k2-fsa OmniVoice — all die on the same onnxruntime .pyd revocation; NaturalVoiceSAPIAdapter and WebView2 remain dead ends.

**Recommended stack:** edge-tts as the daily driver (Edge-quality voices, no browser), Kokoro as the offline/private fallback, benchmark Chatterbox Nano/Turbo on your CPU as the upgrade path, Groq Orpheus as the API-shaped option when you want documented privacy terms.
