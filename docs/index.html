THE CLIMB — ELEVEN RUNGS, AND WHAT EACH ONE COST

Every rung is TWO claims wearing one name: a POWER it gains, and a BOUND on the hazard that power creates. Step through them. What is already earned stays lit beneath, because the point is what accumulates; what is not built yet says what it is waiting for.

  1. R0THE LOOP SURVIVESPROVEN

    Before anything can think, it has to still be there tomorrow. This rung is only about staying alive across being switched off - it adds no ability at all, and it is first because everything above it is worthless without it.

    246.9 h unbroken, 188 ticks, 0 crashes - the gate is 72 h

  2. R1THE DECISION IS READPROVEN

    There were two loops here: one that thought and could not act, one that acted and could not think. This rung is the wire between them - the thinking loop's answer is now read first. It is a small change and it is the moment deliberation stopped being decoration.

    61 of 63 comparable ticks chose differently from the floor

  3. R1.5THE DECISION IS PARSEDPROVEN

    Between deciding and doing there is a translation step, and it is where most systems of this kind quietly break: the reasoning says one thing, the parser hears another, and nothing records the gap. This rung does only the translation, so that when it is wrong you find out.

    83 parses, 3 receipts, 0 swallowed

  4. R2THE DECISION IS A TOOL CALLPARTIAL

    An intention is a sentence, and nothing can execute a sentence. This rung turns a decision into an instruction a machine actually carries out - and at the same time puts a wall between what the system says and what it is allowed to hand to a tool.

    54/20 invocations, 3/3 tools, 5/8 situations

  5. R3THE OUTCOME IS REMEMBEREDPROVEN

    Until now it remembered what it meant to do, never what happened. Improvement is exactly the gap between those two, so this is the first rung where the word learning is defensible - and only in the narrow sense that a prediction was made and checked.

    92 graded outcomes, 18 non-repeats, bound PASS over 57 paired witnesses

  6. R4PERCEPTION BECOMES A CHOICEFUTURE

    Fixed inputs are not perception. This is where the system starts deciding what it wants to know - which is also the first point at which it can send something out of the machine, and that is why it is fenced before it is built.

    — waiting on dispatch (built, canary-gated, unwired)

  7. R5RESEARCHFUTURE

    A summary cannot be wrong, which is exactly why it cannot be useful. Research means committing to something that reality is allowed to kill - so the test of this rung is not what it found, it is whether it ever admitted being wrong.

    — waiting on R4 (egress) and R3 (storing what came back)

  8. R6REFLECTIONFUTURE

    Storage and recall already work. This is the step where something notices what several memories mean together - and the hard requirement is that the new thought keeps a thread back to what produced it.

    — waiting on R5 (material worth linking)

  9. R7THE COUNCIL ON ITS OWN PLANSFUTURE

    This is what it means for a system to be able to disagree with itself. It is also the easiest thing in the whole ladder to fake, because a review that always approves looks exactly like a review that is never needed.

    — waiting on R3 through R6 running with a track record

  10. R8THE DRIVEFUTURE

    Wanting something is not a feature you add; it is a target you can be tricked by. This rung stays shut, and the reason it stays shut is that nobody has solved it - not this project and not the published literature.

    — waiting on an unsolved research problem, not code

  11. R9SELF-MODIFICATIONFUTURE

    The top of the ladder, named here so that nobody arrives at it by accident. It is listed as closed rather than omitted, because a ladder that stops before its last rung invites someone to assume there is nothing above.

    — waiting on every rung below it, and a statable hazard
