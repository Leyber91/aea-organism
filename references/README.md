## PRIVACY GUARD — read before adding anything from PORTFOLIO

The PORTFOLIO project contains career/employer/NDA/personal material that must never enter this
repo (it is backed up to a repo under Luis's real public name). Before any portfolio file is copied
here it is privacy-scanned: **no employer or client names, no NDA or multi-employment references,
no compensation/contract data, no local filesystem paths, no personal identifiers.** Only
game-relevant, anonymised reference material comes in. (This is the same guard that caught
`data.js` leaking "<REDACTED-EMPLOYER> / Amazon / NDA" during the AEA_GAME backup.)
