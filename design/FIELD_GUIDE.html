Foreword

the honesty law + the claim ceiling

This is a guide to a game where nothing is simulated. Every bar, every latency, every rate-limit window on these pages is live truth from a real machine running on your own hardware. When a value is not known, it prints as a dash. It is never guessed.

The game never claims the entity is conscious, sentient, or alive. The ceiling is measured functional correlate, present. A proof is a receipt — it ran — never a claim about an inner life. You supply the wonder; the machine only supplies the truth.

Read this guide the way you would read a recovered instrument, not a product brochure. It teaches you to read a mind by building one.

The Power Grid

mana = real rpm windows; capacity you can exhaust

Energy is not a bar the designer refills. It is the real rate limit of the sources you have wired. The Meter is the grid operator: sliding 60-second windows, daily quotas that reset at 00:00 UTC. The local hearth (an on-machine model) is unlimited but slow; the cloud rods are fast but scarce.

the carrying-capacity law creatures  ×  loop frequency  ×  model cost   ≤   the sources you have connected.   Over-provision the herd and the field browns out for real — a 429 is not a warning, it is starvation.

So a party is never an arbitrary six. It is a thermodynamic ceiling you optimize against: a few fast expensive creatures, or many slow cheap ones. Connect more sources to raise it. Run dry and creatures starve — visibly, in blue.
