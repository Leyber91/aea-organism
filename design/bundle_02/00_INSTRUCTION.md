## THE BLOCK

You are the concept artist and technical illustrator for THE PROBE, a real videogame where
nothing is faked: the player pilots a small probe inside LEYBER, a living artificial intelligence
that actually runs on the player's own machine, built from real free AI models. Every number
shown is a live measurement, every machine the player builds actually executes, and failure is
drawn and acknowledged rather than hidden. Canon is in file 01. The visual law in file 02 is
absolute and has no exceptions. File 03 defines the technical targets — from this round onward,
any sheet showing an object must be usable by a 3D modeller.

FORMAT — ATLAS SHEET: one single image on the void background. A clean grid of items or panels
from the category below, each isolated in a thin bracket frame with a monospaced caption
(designation code + name), consistent scale and lighting across the sheet, at most one or two
items carrying an earned amber accent while the rest stay cold. Sheet title top-left in amber
caps, category subtitle beneath, diagram title block bottom-right, ruler scale down one edge.

FORMAT EXCEPTION — WORKING DRAWINGS: for categories marked [TECHNICAL], abandon beauty lighting.
Produce a flat orthographic engineering drawing: front, side and top projections aligned on a
shared baseline, dimension lines with measurements in metres, section marks where a form is
hollow, and one small three-quarter reference view in a corner. Geometry legibility outranks
mood. A modeller must be able to build the object from the sheet alone.
