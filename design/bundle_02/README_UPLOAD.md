# BUNDLE 02 — everything

41 MB · 5 instruction files + this readme · 39 chapters in `full_book/` · 24 sheets in `sheets/`.
All markdown privacy-scrubbed: no employer names, no local paths, no personal identifiers.

## The problem with uploading everything, stated honestly

ChatGPT will not usefully absorb 39 chapters and 24 images in one conversation. Attention
degrades badly past roughly 10-15 documents, and when it degrades it does not announce it — it
quietly starts inventing. That is the failure mode that would cost us the visual law.

So: **everything is here**, but upload in layers.

## LAYER 1 — the actual upload (send this)

The five root files plus three or four sheets. This is the refined bundle, built for the job:

## LAYER 2 — add one chapter when a sheet needs deeper canon

Pull the single relevant chapter from `full_book/` into that conversation:

- a **district or landscape** → `01_WORLD.md`
- a **mission moment or story beat** → `A12_STORY.md`, `05_CONTENT_MISSIONS.md`
- **element seals** → `A8_AEA_ALIGNMENT.md`, `aea_elements.js`
- **UI or panels** → `04_UI_BIBLE.md`, `E4_UX_P0.md`
- the **look itself** → `E2_VISUAL_DIRECTION.md`, `A11_SIGNATURE.md`
- **3D and Blender questions** → `E5_3D_TRANSLATION.md`

## LAYER 3 — the whole book, for carrying not uploading

`full_book/` holds all 39 documents: the complete design book, the production manual, the
prototype ladder, the coverage audit, the engineering chapters, plus `aea_elements.js` (the raw
canon the game actually runs on). It is here so the bundle is genuinely complete and portable —
one folder that carries the entire project.

**Seven carry working context** — build order, session budgets, risks, the ticket registry, the
product path: `09_PRODUCTION.md`, `P0_PROTOTYPES.md`, `INDEX.md`, `BOOK.md`,
`E1_CODE_ARCHITECTURE.md`, `E3_TRACKING.md`, `A5_PHASE_B.md`. Nothing in them is secret and every
identifier is scrubbed, but they describe how we work rather than how the world looks, and an
image generator has no use for them. Upload them only if you deliberately want an outside model
reasoning about the project's plan.

## `sheets/` — the 24 finished sheets

`S1-S8` scenes · `A1-A7` object atlases · `B1-B9` the codex (all 29 architecture elements have
seals). Round 3 extends these; it never replaces them.
