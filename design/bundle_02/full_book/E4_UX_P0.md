### 1.3 Verdict

**DESIGN C — THE BENCH FROM THE SESSION — wins.** It is the only design whose every
surface answers a session moment, it is the smallest honest build, and it commits no
law violation. Design A, the close second, carries three latent violations that
surfaced only under audit: its empty socket circles are decorative rings (banned by
A11 §3.1 — a ring cites the map or does not ship; C's gap-in-the-hairline IS the
socket and invents no mark), its key E invents a second interface key against the
one-verb-one-key grammar (A1 §7), and its permanently-warm proven-part glyphs add
idle amber outside A11 §4.1's closed list without naming the amendment. Design B is
not wrong — it is early: its center of gravity is a P10 HOME question, and its best
organ survives below as a graft.

The win is a skeleton, not a sweep. Six organs are grafted from A, three from B,
each named and argued. Organs refused are named in §12 with the law that refuses them.

## 2. DESIGN THESIS

The bench is the room where ten minutes reliably become one measured truth. One
docked surface — THE PLATE — carries composing, running, failing, and reading,
because the trace must walk the very wires the player laid (R1 findings 5–6;
A11 §3.2), and a separate results screen would remove the player from their machine
at the exact moment it proves itself. The plate is a left-to-right SPINE: the grid
trunk enters at the left edge — the trace arrives FROM the world — and the record
book closes the right. A gap in the spine's hairline is a socket; seating a part
closes the wire. The world stays in frame behind the plate, live and un-paused, so
that when the machine draws, the world visibly answers (the serving plant flares) —
the bench is a limb of the same body, not a menu over it.

Master-craftsman feel comes from three properties, each law-mandated: edit and
execution share one surface at one scale; failure is located, not summarized
(R1 finding 6); and the door out of a session is a measured record, never a medal
(R1 findings 9, 12). The plate's own ink obeys the signature: nothing unfired earns
amber, so the plate is a save file at desk scale [GRAFT-A2] — a stranger who knows
the rule can order two bench screenshots in time.

## 4. ENTRY AND EXIT — edited 2026-07-20 (verifier closure)

**Placement law (re-derived, not inherited).** R1 finding 7 fixes the bench as a
place — "a test range at the home" — and FLY is how the world is memorized (A1 §7);
but the ten minutes are sacred, so the toll of reaching a place you own is seconds,
not a journey. The slab sits within ~15 seconds of flight from boot spawn. At P0
that site is the nexus (P0 SPEC ADDENDUM placement, kept BY ARGUMENT: the home does
not exist until P10; the deferral is evidence-based sequencing, named so P10 is a
move, not a rebuild). No teleport, no menu shortcut: a bench you can teleport to is
not a place.

**The slab [GRAFT-B2].** A low dark slab of world geometry, its spine a structure-ink
hairline, wired into the grid by a real trunk line — visibly a limb of the same body.
Zero idle amber: an unrun bench has earned none (A11 §4.1). One window warms only
once a passing record exists [GRAFT-A5, pending D-E4-2 — [P1] under THE P0-CUT;
at P0 the slab stands all structure at idle]. It stands before the
mission names it.

**The prompt.** Within ~12 m: `F — THE BENCH`, 10px uppercase, structure 0.6, above
the slab. **Anchor argument, recorded:** this converges on the existing proximity-
prompt grammar and the existing F interface key. It survives because all three blind
designs re-derived it independently from first principles — a place-based capability
requires a physical affordance AT the place (Discoverability clause 4c: a capability
that cannot be found does not exist), and INTERFACE is one verb (A1 §7), so it earns
one key, and that key already exists. Inventing a second interface key (design A's E)
is refused in §12.

**Dock (F).** Camera eases 400 ms, damped, to a fixed high oblique over the slab —
one move, serving readability only (A11 §6.6) — framed so the foundry row sits in
the middle distance behind the plate (the world-answer needs it in frame, §8.3).
Plate opens per recipe: brackets scale-in 140 ms, hairlines draw left-to-right
180 ms, rows fade+translateY(6px) at 30 ms stagger, 160 ms each, total <= 450 ms;
40 ms square blip; 55 Hz hum gain 0.05 while docked. The world never stops behind it.

**First relevance feed line** (Discoverability clause 3, once per event class):
`BENCH STANDING — F AT THE SLAB`. The hint bar gains no entry — path (c) satisfies
clause 4, and new chrome enters only by displacing old chrome (A11 §4.3).

**Exit (F or ESC).** ESC cascade: close inspect strip, then undock. **Anchor
argument, recorded:** this converges with the build's layered ESC and survives by
re-derivation, not inertia — 04 §2's ESC-cascade law is one grammar (a close key
closes the topmost layer first), the plate is a layer stack like any other (strip
over plate over world), and inventing a second close grammar for the bench would be
new chrome displacing nothing (A11 §4.3). Close = 200 ms
fade+scale(0.98), always faster than open. The construct is a file; the plate state
persists exactly. Exiting during a live run is legal — the run is real and continues
server-side (run contract, P0 addendum); its completion lands in the feed and the
record book. The game never pretends the machine needed you watching.

## 8. RUN — THE LIVE TRACE, TO THE MILLISECOND

### 8.1 Fire

`SPACE`. Within 100 ms: the spine locks, seated chips settle to their earned ink,
the run log opens `RUN r-nn · T+0.00s`, and the control line flips to
`PLATE LOCKED — RUN LIVE`. The run executes through the REAL router in its own
server thread (run contract: `POST /api/construct/run` returns run_id; the plate
polls; every bench event is run-tagged so the entity's own concurrent draws can
never be misattributed to the wire).

### 8.2 The packet — the game's only traveling light

- The packet — head hot `#ffb000`, tail cooling through `#d4a24c` (E2 move 8) —
  enters from the LEFT EDGE along the trunk wire and walks the spine. It exists only
  over a logged call. No fake traffic, ever (A11 §3.2).
- **It moves only when data actually moved.** Hop advance is a 160 ms eased glide
  (inside the 120–500 ms motion law). At the part that is actually working, the
  packet STOPS and SITS — hot, still — while the real work happens. The live counter
  `T+n.nns` at the packet head, 20 px amber (the plate's one display-size number,
  04 §0 type law), ticking in real elapsed time, IS the animation. No pulse, no
  spinner, no synthetic pace: the wait is the drama (A1 §5), and the trace is the
  waiting state (R1 finding 5).
- Real sub-events are micro-hops: on the LADDER, one micro-hop per `tried[]` receipt
  — the packet visibly falls past dead rods. A plant-kill on a healthy grid renders
  as these reroute marks and a PASS: that is resilience working, not failure
  (P0 addendum, the honest kill).
- Hop complete: 40 ms square blip; the part's value flares hot 120 ms and decays to
  warm over 600 ms (attack/decay law); the packet advances. Traversed wire cools
  hot -> `#d4a24c` -> structure over 600–900 ms — afterglow is a fading proof, never
  a persistent glow.
- Every hop lands a receipt in the run log as it happens, real units, no euphemism:
  `HOP 1 · TAP · DRAW OPEN · T+0.32s`
  `HOP 2 · LADDER · <rod> DEAD · FELL THROUGH · T+1.88s`
- Per-link milliseconds come from the harness's own perf_counter around each fire —
  never energy.draw's rounded latency (run contract).
- One packet, one run at a time. No queue, no parallel fire: the player watches the
  thing that is actually happening.

### 8.3 The world answers [GRAFT-B1]

While TAP's POST is genuinely out, the serving plant's windows flare in the middle
distance — the existing flashNode emissive event (+0.9, 650 ms, eased home), fired
by the same real draw, visible in frame because the bench camera faces the foundry
row (§4). The world dims for no panel and stops for no bench; a REAL event elsewhere
(a tick, a rot, a 429) prints as a single 0.35-ink line in the run log — REAL events
are a story channel (A12 §5.3) and never interrupt.

### 8.4 A CONSTRUCT'S FIRST RUN — the sanctioned ritual

On the final hop of THIS construct's first passing run, exactly as legislated
(A11 §5): the completion sting, and the seated parts flash once in family order —

## 9. FAILURE — INSTANT, LOCATED, HELD [GRAFT-A3]

The moment a hop truly fails — rods exhausted, window empty, wall refused — the run
halts THERE. Deferred failure is a scored design defect (R1 finding 6).

To the millisecond:

- T+0 ms (the real failure lands): the packet stops ON the wire where it died and
  cools in place, hot -> warm -> structure, over 900 ms. It does not travel to an
  error state; the error state is where it stands.
- T+0–200 ms: everything else on the plate eases to 0.35 ink. The failing part's
  name holds at 1.0 structure. No third hue exists — failure is amber WITHDRAWN,
  the light going out, which is the honest picture (two-ink law as dramaturgy).
- The halt receipt prints in the log, true cause, no euphemism:
  `> HALTED AT LADDER · ALL 4 RODS COOLING · NEAREST WINDOW 41s · T+7.21s`
  `> r-08 APPENDED · FAILED AT HOP 3 · COST 1u`
- No sound but the hum. Silence is canon (A12 §5.5); silence is the failure sting.
- The frame HOLDS until any input — deliberately composed to be screenshot-worthy
  (A11 §5: losing well is part of the autograph): one cooled trace, one named wire,
  the live world behind. Any input returns to COMPOSE.
- The failed seat keeps a small structure-ink tick for the rest of the visit —
  settled story cools to structure (A12 §5.8) — so the edit target stays findable
  without amber lying about liveness.
- The failed run APPENDS to the record book as a run (§10.1). Append-only, never
  rewritten (pr.time bench law, A13 §2.6).
- No retry theater: RUN again IS the retry, at its real cost, and the GOVERNOR chip
  shows the window genuinely recovering.

The honest kill for the P0 exit-criterion demo (addendum, kept): zone=sensitive with
local ollama down — genuine starvation. A plant-kill on a healthy grid reroutes and
passes, and must render as exactly that.

## 10. THE MEASURED RECORD — edited 2026-07-20 (verifier closure)

### 10.1 The row

Run ends -> one row appends within 100 ms. Real values, four axes, no composite
score, no medal (R1 findings 8, 9, 12):

```
 r-09 · 20:41 · SPEED 4.10s PB · COST 2u · HOPS 5/5 · ZONE PRIVATE
 r-08 · 20:36 · FAILED AT HOP 3 · COST 1u
 r-04 · 07-02 · SPEED 3.42s · COST 1u · HOPS 2/2 · ZONE PRIVATE
```

- **SPEED** wall-clock (harness-measured) · **COST** quota units actually spent ·
  **RELIABILITY** clean-hop fraction, fall-throughs counted · **PRIVACY** the highest
  zone the route touched (seed.9's rings as data). At P0 every axis comes from the
  run receipt's measured fields ONLY — no model-judged quality number exists (an
  invented number would be the first dishonest pixel; P0 addendum SCORER contract).
- A personal best on ANY axis flares that number hot 120 ms, decays to warm over
  600 ms, and marks `PB` on that axis only. Open target: no "done", only your own
  edges. One-line `LAST n.nns · BEST n.nns` readout stands above the rows —
  R1 finding 12 at minute one (addendum rider, kept).
- [P1] under THE P0-CUT (item 1): the rows and the per-axis PB flares are P1
  surface. At P0 every run still appends server-side to the append-only runs.json
  from birth (grid.file_lock / atomic_save_json — E1 §7.6 mandates it), so no data
  is ever lost and P1 builds only surface; the P0 region is the `LAST/BEST` readout
  plus the run log, the addendum rider verbatim.

### 10.2 The no-replay law

`UP`/`DOWN` walk rows; `ENTER` unfolds a row's stored receipts in place, settled
structure ink. A record NEVER re-animates the trace: a moving light means live
routing NOW, and that learned meaning (A11 §3.2 — the eye learns it in minutes) is
never spent on a replay. History is read, not re-performed. [P1] under THE P0-CUT —
the walk lands with the rows; the law itself binds P1's build.

### 10.3 The return line

The record book leads with deltas computed from live state only:

`SINCE LAST VISIT · RODS 44 -> 29 · r-04 ROUTE CROSSES 2 DEAD RODS`

This is the honest hookshot (A13 §5) and R1 finding 8 made into the session's
motive: model rot IS the drift, so a return weeks later opens on the standing
question — does my machine still hold? A reason to run that no quest arrow could
match and no line of copy invents. The task card restores the last selected task;
a returning player is composing inside one minute of boot. Traces are append-only;
a revisit that found the numbers identical would be evidence the process died, and
the game says so (CARRIER LOST, A10). [P1] under THE P0-CUT (item 1) — the return
line lands with the rows, and its `SINCE LAST VISIT` delta needs a persisted
last-visit snapshot no P0 contract stores; P1 must spec that store when it builds
this surface.

   the animation.

   A11 §1 dies. Failure is amber withdrawn — the light going out is the honest

7. **Replaying traces from records.** Moving light means NOW (A11 §3.2). A replay
   would spend the game's most carefully taught visual meaning on a lie of tense.
8. **Hold-to-run (design B's commit arc).** The hold ritual is reserved for
   destruction (04 §0); bench runs are reflex-tier cheap BY DESIGN (R1 finding 7 —
   the GOVERNOR crossing exists precisely so running is never a ceremony).
9. **A pre-seated smoke rig (design B's resolution).** On a plate, seating costs one

10. **Socket iconography (design A's ring-mouths).** Any circle sharing a center

11. **A second interface key (design A's E).** One verb, one key (A1 §7). The bench
    inherits F — by re-derivation, §4.

14. **The OS tab and the dock-terminal pattern** — see §13, rulings 2 and 3.
15. **A model-judged quality axis at P0.** Measured fields only (addendum). The
    first invented number would be the first dishonest pixel on a surface whose
