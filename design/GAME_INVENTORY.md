# GAME_INVENTORY — the complete element bill-of-materials for THE PROBE

*Built by the element-inventory panel (wf wbxjuh3mk, 6 lenses + synthesis + adversarial critic), 2026-07-24.
"Inventory" = everything that composes the game — verbs, entities, surfaces, progression, meta, modes,
systems — not just objects. This is the scope contract; the guided-complete checklist + priority order at the
end are what we actually build. Full per-element detail: the workflow transcript.*

## THE SHAPE (one paragraph)

One game, **three apertures over one engine**. You pilot a speck-scale probe through a REAL running AI entity
(the two-tori instrument, ember-in-cage organs, four privacy rings), fly to a lit beacon, **DOCK**, and drop
from flight into a machined **bench** where you **SEAT** real parts and **IGNITE** them — every ignition a
live metered call to localhost that can answer, starve, or fall through; every bar/number a real receipt
(absent renders a dash, never a guess). The receipt lands as *drama, not a table*. When a construct runs
DIFFERENTLY it **EARNS a doctrine name** in the one lawful amber text — which lifts an organ's fog, grows the
world, de-fogs a codex node. The spine is the **8-rung COMPLETENESS LADDER**, each rung a visibly different
silhouette and a bigger part-pool, tracked on a **journey map** and a **codex** so the player SEES themselves
becoming more complete. **GUIDED** is the newcomer aperture (on-rails, fire pre-wired parts, close on rung 2
with the first earned title); it graduates into **BUILDER** (wire freely) and **ARCHITECT** (edit crystallized
code) along a depth dial, with an orthogonal **SANDBOX↔LIVE** reach gate that governs how far the entity's
HANDS reach — never whether the brain is real. The win condition is a **measurement** (Class-2 via a real
endurance run), never a claim.

## THE INTERACTION MAP (the loops elements form)

- **The guided minimal loop** (must pass the boring test): world → lit beacon → FLY → DOCK → LEARN (one
  concept) → SEAT (one legal chip, you author it) → IGNITE (a real metered call) → RUN-WATCH (the tried-list
  animates) → READ-RECEIPT (reveal, not a table) → PROVE (a real assert) → EARN (amber title stamps) →
  REVEAL/LIFT-FOG (an organ lights, the world grows) → codex de-fogs + map advances → next beacon.
- **The honesty loop** (binds every DO): action → real localhost call → real receipt → reach-mark stamped
  (hearth/reached/starved) → one honesty tag → absent value renders a dash. No cosmetic particle without a
  real event.
- **The progression loop** (Spore spine): ship a construct that adds an organ/part → rung completion →
  **stage silhouette transforms** (not more dots) → part-pool unlock → codex de-fogs → autonomy battery
  re-reads → completion track ticks toward THE WHOLE ONE.
- **The depth-dial slide** (three apertures, one save): GUIDED (fire pre-wired) → graduation (first self-wired
  construct that runs) → BUILDER (wire freely, meet the viability spectrum) → crystallize → ARCHITECT (edit
  that behavior as real code) — all over the same gameapi + composer + sacred save.
- **The anti-dashboard web**: every silent state-read bound to a felt channel (fire-flash, the tried-list,
  fog-lift, live bars, the cost-meter, the amber title stamp). A dashboard is silent and fakes a number; THE
  PROBE is kinetic and shows a dash when a value is truly absent.
- **THE MERGE** (the load-bearing seam): DOCK → flight→bench dive → the bench plate and back, as one
  continuous program. *Until world.html and web/game/ are unified, the guided loop cannot be played
  end-to-end.*

**Shared engine (the anti-fork spine):** all three front-end the same `aea/gameapi` and run on the ONE
composer (`bench_core`) that re-walks a construct's wiring and fires each part's REAL organ entry point — no
second execution engine. Same 5 fireable parts (fired/wired/extended), same 4 live organs lit only by a real
signal, same laws (honesty + dash, zone arithmetic, the gate law, part-signature identity, energy continuum,
fog-of-war), ONE sacred save across apertures. Modes are onboarding presets / a depth dial, not products.
Gentleness in GUIDED comes from the free local HEARTH + real replayed traces — never from lying.
