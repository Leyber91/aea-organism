## STYLE LAW (hard constraints)

- Field: near-black blue-void `#06090e`–`#0c131c`. The frame is MOSTLY dark. Vast negative space.
- Structure ink: thin steel grey-blue `rgb(120,155,175)` hairlines — quiet, precise, never bright.
- Cold accent `#24394a`–`#5bb0d6`: ONLY for unearned/fog/ghost elements.
- AMBER (`#ffb000` hot, `#d4a24c` warm): ONLY the fired/alive/earned state. Sparse, concentrated,
  EMITTED from within a structure. The single brightest element in frame.
- Materials: matte near-black, faceted dark geometry, machined hairline edges. Light does the talking.
- Composition: radial order, intentional shapes, one focal amber event. Nothing scattered.
- FORBIDDEN: multicolour/neon, lens flares, gloss, rounded consumer UI, bright skies, ornament,
  greebles, people or hands, ANY text in this frame (photo mode), watermarks.

## THE GAME (context)

The player flies a tiny probe inside a real, living AI entity. The entity's body is a vast dark
radial instrument in a void. Every light is a true system event — the world is beautiful only in
ways the truth permits.

## THE MOMENT (the save-state of this frame)

Mid-game, idle cruise. No run is firing. The entity's heartbeat is alive, so its core burns calm
amber. Four organs have been earned and burn; two are still unearned fog. One heartbeat event is
in transit along a spoke. Photo mode: the HUD is hidden.

6. **THE HORIZON:** a faint cold band far in the distance, barely there.
7. Everything else: black void. No stars, no text, no probe in this frame.

brightest element; the lit nodes second; the fog nodes barely visible. Still, silent, austere —
an astrophysics render of a machine that is quietly alive.
