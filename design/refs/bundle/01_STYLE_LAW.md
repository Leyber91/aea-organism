# 01 · STYLE LAW — the visual constitution of THE PROBE

This file governs every generated image. If an image violates a line here, it is off-brand
regardless of how good it looks. Attach this file to every generation.

## The one-line soul

**A truthful instrument in a void: everything is dark and quiet until something REAL fires — and
then one amber event burns.** Beauty comes from restraint, precision, and the feeling that every
light means something actually happened.

## Palette (strict — two inks + one accent)

- **The field:** near-black blue-void. Deep values `#06090e` to `#0c131c`. The frame is MOSTLY this.
- **Structure ink:** desaturated steel grey-blue `rgb(120,155,175)` — thin hairlines, rings, spokes,
  wireframes, small type. Quiet, never bright, never thick.
- **Cold accent:** dark cyan-blue `#24394a` → `#5bb0d6` used sparingly for unearned/fog/ghost
  elements and faint atmosphere.
- **AMBER — the only warmth:** hot `#ffb000`, warm `#d4a24c`. Amber is the FIRED/ALIVE/EARNED state
  ONLY. It is sparse (a few percent of the frame at most), concentrated, and always **EMITTED** —
  light coming from within a structure (a core, a pulse, a seam, a lit node) — never a paint tint,
  never a decorative wash, never a warm sky.
- Absolutely nothing else. No rainbow, no purple nebulae, no green, no white backgrounds.

## Type (for any interface/FUI in frame)

- **IBM Plex Mono** only. Uppercase, letter-spaced labels. Tabular (fixed-width) numerals.
- Text is small, precise, engraved-feeling — a laboratory readout, not a poster.
- **Any visible text must be REAL words taken from the scene file.** No gibberish glyphs. If the
  generator cannot render a label cleanly, prefer fewer, larger, correct words.

## Register / lineage (what it should feel like)

Duskers' diegetic terminal dread · Territory Studio FUI (The Expanse's console language) ·
2001 / Interstellar instrument restraint · high-end astrophysics visualization (accretion-disc
renders). It is a WORKING INSTRUMENT someone flies inside — not a game menu, not a hologram toy.

## Materials & light

- Matte near-black surfaces; faceted dark geometry; thin machined hairline edges.
- Light does the talking: rim-light, emission, bloom on amber only. No global brightness.
- Fog/atmosphere is subtle and cold, used for depth, never milky.

## Composition laws

- **Vast negative space.** The frame breathes; the dark is a feature.
- **One focal amber event** per image — the single brightest element, deliberately placed.
- Structure (rings, spokes, hairlines) is quiet and precise — an engineer drew it.
- Symmetry and radial order over scatter. Shapes must read as INTENTIONAL: circles, radial spokes,
  clean ladders, milled plates. Never a tangle, never clutter.

## FORBIDDEN (instant fail)

Rainbow or multicolour palettes · neon cyberpunk clutter · lens-flare soup · toy/cartoon/rounded
consumer UI · glassmorphism gloss · bright or warm skies · fantasy ornament · greeble noise ·
people, faces, hands · gibberish text · watermark/logo styling · anything that looks like a
generic sci-fi HUD template.

## The honesty tell (the soul, restated as a check)

Ask of every glowing thing in the image: *"what real event is this?"* If the image invents glow
with no imaginable cause — it is wrong. The brand is: **beautiful because true.**
