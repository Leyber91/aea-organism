# THE WHOLE GAME — vision posters (the entire PROBE in six comprehensive images)

These are NOT the narrow single-moment build-refs (01-12). These are VISION posters: each holds a whole
slice of the ENTIRE game — the AEA theory, our intentions, the design, and the critique — imagined at
monument scale in THE PROBE's two-ink language (near-black void, engraved steel-grey, amber = earned only).
Grounded in GAME_INVENTORY.md. Generated the same way (attach a locked ref for material, paste the prompt).

Anchor per poster: V1/V2/V6 attach REF-06 (world) · V3/V4 attach REF-10 (bench/chip material) · V5 attach
REF-08 (the milled-groove receipt material). One image per message; fix one quoted string at a time.

Field-lesson carry-over: stage MATTER not information (these are monumental physical objects photographed,
not flat infographics); counts stated twice; amber only on earned/real; text is debossed structure-grey
(the ONE lawful amber text is an earned title). If a poster's text overloads, keep the FAMILY labels + drop
the leaf labels — structure over completeness.
