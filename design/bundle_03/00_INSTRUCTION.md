# BUNDLE 03 — INSTRUCTION · SIX SHEETS, SIX BLOCKS

## How to run this

1. Upload this whole bundle in one message. It carries the canon, the visual law, the sheet index
   of everything that already exists, and file `07` — the five levels of the founding manifesto,
   which two of these sheets close.
2. Then paste **ONE CATEGORY BLOCK PER MESSAGE**, in the order given below. Never two.
3. Judge the sheet that comes back against the block's own honesty register — is every amber mark
   earned, is every unmeasured field drawn empty, is anything drawn as a face or a figure.
4. Only then paste the next block.

Six blocks follow: **3 · 4 · 5 · 6 · 8 · 9**. Numbers are stable ids from the coverage census; they
are not a count and they do not renumber. (Batch 1 has shipped. Batch 2 is blocked on unwritten
canon and is not in this bundle. Batch 7, 10 and 11 are build and verification sessions, not
drawings.)

Study the finished sheets in the index before drawing. Match their line weight, their caption
discipline, their restraint with amber, and their title-block conventions. Where a new sheet
touches a subject an old sheet already carries, it must ADD what the old one could not: a state, a
transition, a measurement, a negative result.

## STYLE CONSTRAINTS — restated, absolute, no exceptions

- **TWO INKS ONLY.** Void `#050a10`–`#0a1420`. Structure `rgba(120,155,175)` at .70 / .45 / .28 /
  .14 / .08. Amber `#ffb000` hot and `#d4a24c` warm — **only** where a thing is genuinely alive or
  the result was genuinely earned. No third hue. No red.
- **SIX GLYPH SHAPES ARE THE ONLY ICONS.** circle · pentagon · hexagon · triangle · square ·
  diamond. Established meanings: circle = seed, pentagon = axis, hexagon = principle, triangle =
  verb, square = mechanic, diamond = operation. Nothing else may function as a symbol.
- **FLAT TECHNICAL-BLUEPRINT RENDERING.** Hairline construction, orthographic, no beauty lighting,
  no atmosphere, no lens effects.
- **MONOSPACED TERMINAL TEXT AS TEXTURE.** Captions, receipts and log lines are part of the
  drawing.
- **CORNER BRACKETS, NEVER BOXES.**
- **NO EMOJI. ANYWHERE.**

### THE STANDING RULE — it governs every block below and overrides any panel instruction that seems to contradict it

You do not have access to this entity's record, so you cannot know any result. Draw the instrument
— the frame, the field, the label, the unit, the axis, the layout of a fact — and inside every
value slot, print `unmeasured`. **No verdicts, no filled bars, no plotted curves, no rankings, no
invented identifiers.** A field is honest; a reading you did not take is not.

Earned the hard way: a sheet commissioned with pass bars and a plotted trend came back with twelve
fabricated `PASS` verdicts and a confident rising curve beside its own ratio box reading
UNMEASURED. It was rejected. The redraw, which asked for no readings at all, came back clean.
Removing the request removed the fabrication.

### EIGHT CRAFT CHECKS BEFORE YOU FINISH — each has already gone wrong on a shipped sheet

1. **Spell the names.** Three sheets have now shipped a transposition in a heading
   (`MILLISECENDS`, `THE BENCH SIUTE`) while spelling the same word correctly elsewhere on the
   same plate. Read every heading back.
2. **A uniform grid stays uniform.** If a set of elements shares a form, every one is the same
   width, the same height, and carries the same number of segments — and **every** member is
   present. Nine boxes where ten belong is a claim about the tenth.
3. **A dashed region is dashed all the way down.** Not just its outer frame and its sub-panels —
   the slots, boxes, cards and internal linework inside it too, one opacity step colder than built
   stock. The test: crop any single element out of that region and it must still read as unbuilt.
   The uncertain region must never carry hotter or brighter ink than the built ones.
4. **Every inscription legible at 1:1.** Set `unmeasured` at the same size wherever it appears.
5. **Do not print an instruction word as a value.** Where a brief names a row — "its `TYPE:` line"
   — the word `line` is the name of the row, not its content.
6. **The six-glyph strip carries its caption**, `six glyphs. one language.` The caption is what
   makes the strip a key rather than ornament, and those six shapes may never be ornament — nor
   row bullets, nor medallion frames, nor decoration inside a station mark.
7. **The edge ruler is a real scale.** Every labelled interval spans the same distance as every
   other, including the last, and the origin is labelled `0` — not `00`. Three sheets running have
   shipped a final interval at a third of its own pitch on a plate reading `SCALE 1:1`.
8. **A list of examples is not a list.** If a callout enumerates two of several possibilities,
   say so — `+ further categories · unenumerated` — or name them all. Two cited examples presented
   as a complete set is a quiet over-claim.
- **NEVER DRAW THE INTELLIGENCE AS A FACE, A FIGURE, AN EYE, OR A ROBOT.** It is a place, a
  circuit, an instrument, a record.
- **NEVER DRAW A NUMBER THAT WAS NOT MEASURED.** Where no value exists, draw the field empty and
  inscribe `unmeasured`. An empty field is honest; an invented one is a forgery.
- **EVERY ITEM CARRIES ONE PLAIN-LANGUAGE LINE.** Beneath each item's designation and name, set
  one short sentence in structure ink saying what it actually does, in ordinary words — the way a
  filter reads "does this match the weather?" rather than only `trigger_fit`. The drawing carries
  the form; the line carries the meaning. A sheet that names without explaining is a catalogue,
  and this project is a teaching instrument.
- **MATCH THE REFERENCE SHEET `B10_innovation_layer_V2`.** It is the tone, density and composition
  target for every sheet in this bundle: distinct glyph-keyed items, directional flow drawn with
  amber arrows only where the flow is real, region titles in amber caps, a demo tag on every panel
  whose subject is not yet wired, and a measured-evidence footer.

**THE HONESTY REGISTER — visible at a glance on every panel.**
`[BUILT]` solid outer bracket, full-weight ink, amber permitted where it actually fires.
`[SENSED / demo]` dashed outer bracket, one opacity step colder, tagged with the experiment it came
from; amber only on the specific sub-item that empirically fired.
`unearned` complete frame, blank readout, the reason for the blank inscribed inside it.

**FORMAT — ATLAS SHEET.** One single portrait image on the void background. Items and panels in a
clean grid, each isolated in a thin corner-bracket frame with a monospaced caption (designation
code + plain name), consistent scale and lighting across the sheet. Sheet title top-left in amber
caps, category subtitle beneath, title block bottom-right, ruler scale down one edge, the six-glyph
strip top-right with the note `six glyphs. one language.`
