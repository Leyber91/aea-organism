# 4. THE TICK ANATOMY — one cycle, step by step

One external invocation = one tick. The order is fixed, and the order is the content: this is
what the machine actually does, every time. `[NOT YET DRAWN]`

Wall time: roughly **30–60 seconds per tick** on a local substrate with the default model set.

```
①  HALT GUARD          if the halt flag is set, do nothing, log the halt, return.
                       The machine that has stopped itself refuses to pretend otherwise.
②  INCREMENT           tick counter +1; the operator's goal for this tick is taken in.
③  MONITORS            lazily start two daemon watchers, once, on the first tick:
                         · the health probe   — is the substrate alive?      (every 60 s)
                         · the pressure probe — memory load + latency trend  (every 30 s)
                       their latest snapshots are read into state every tick.
④  BRANCH SWAP-IN      if running multi-branch, select the active branch and load its state
                       slice. Everything below operates on that slice.
⑤  CATEGORY DISPATCH   ten categories, in this fixed order — this is the spine of the tick:
                         1  RETRIEVE      perception            (seed #2)
                         2  COORDINATE    plan · act · critique (seed #3)
                         3  COHERE        coherence + recovery  (seeds #4, #7)
                         4  SELF-MODEL    introspection         (seed #6)
                         5  CRYSTALLIZE   pattern lock-in       (seed #8)
                         6  FLEXIBILIZE   pattern unlock        (seed #9)
                         7  PEER_DEBATE   multi-perspective check, when scheduled
                         8  HYPOTHESIZE   the innovation layer  (seed #10)
                         9  FALSIFY       adversarial probe, when permitted
                        10  SELF-VERSION  substrate stepping    (mechanic)
⑥  RECOVERY CHECKS     rollback policy (revert a change that did nothing);
                       wall-clock terminate (set the halt flag if stuck too long in
                       real time — not in ticks).
⑦  BRANCH SWAP-OUT     write the active branch's changes back into its slot.
⑧  STALL SIGNALS       compute the stall count and severity that will feed NEXT tick's
                       proposing trigger. The machine leaves itself a note.
⑨  SAVE                atomic write of the whole state object + the skill manifest.
⑩  EXIT                return the tick result; the harness appends one line to an
                       append-only log, and every N ticks writes a full snapshot.
```

Facts that belong on this plate, and no others:

- HYPOTHESIZE is a **no-op on most ticks** — it runs only when a trigger condition is met.
- Longest verified continuous operation: **1499 of 1500 ticks completed (99.93%) across 20.91
  hours**, unattended, with 1 caught tick error and zero halts `[demo]`.
- An earlier long-horizon run: **542 ticks / 8.36 hours**, ending in a real infrastructure
  failure that drove the recovery layers into existence `[demo]`.

**Drawing note.** Draw the tick as a ring with ten stations and a return path — the tick is a
cycle, not a flowchart column. The category dispatch is the widest arc of the ring. Amber sits
on exactly one station at a time: the one currently executing.

# 10. THE FIVE COLLISIONS — read before drawing anything

Five words in this architecture each point at two different things. A sheet that merges either
side of any pair is wrong.

1. **"OPS"** — the four transcendence operations (structural self-change, no glyph) vs the four
   operator-loop ops (design/time/ship/learn, diamonds, already drawn).
2. **"BOUNDARY"** — the axis-reachability filter inside the proposing cascade vs the privacy law
   that keeps sensitive work on the local machine. Unrelated concepts.
3. **"TRANSCENDENCE"** — the four structural operations vs the game's tool-layer seed.
4. **"FLEXIBILIZE"** — unlocking a falsified skill vs route-resilience when a node dies. Same
   deep move (pressure unlocks what repetition locked), different substrate.
5. **"LADDER"** — the six act-indexed rungs of the player's assistant vs the five level-indexed
   axis ladders of the entity's coordinates.

And one word that means the same thing in both taxonomies and can be used freely:
**CRYSTALLIZE** — freeze a repeated behaviour into something callable.
