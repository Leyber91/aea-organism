# BUNDLE 03 — the canon that was never uploaded

**Eight documents plus six reference sheets. Upload all fourteen — well inside the twenty limit.**

## Why this bundle exists

Bundles 01 and 02 were built from the game's 29-element PROOF taxonomy. That taxonomy is a
*projection* of the real architecture — so every stratum it dropped was never drawn, and the
image census found only 24 of 86 canonical items covered. The library was a faithful image of
the wrong list. This bundle carries the missing strata.

## How to run it

1. Upload the eight documents and the six sheets.
2. Paste this opening line:

   "These files are the design canon for a game called THE PROBE. Read all of them before
   generating anything. 02_VISUAL_LAW is absolute and has no exceptions. 06_MEASURED_EVIDENCE
   lists the only numbers that may appear on a sheet — any other figure must be drawn as a
   blank field or a dash. 04_SHEET_INDEX lists what already exists; never repeat it.
   01_CANON_COMPLETE marks some rungs NOT SPECIFIED IN CANON — never draw those. I will send
   one CATEGORY block per message from 00_INSTRUCTION."

3. Send one batch block per message. Judge each sheet before the next.

## The strongest new material

Two things in here will make the sharpest sheets, and neither has ever been drawn:

**The twelve measured null results** — same-model ensembles do not rescue a hard task ·
temperature is not model diversity · a council hurts an easy task · a 4/4 benchmark did not
survive production · 7 perfect scorers fell to 2 in one sweep · 16.8% of emitted actions
invented tool names that did not exist · 5 of 8 triggers never fired · the first reflection was
refused by its own watcher. Negative findings are as citable as positive ones, and a sheet of
honest failures is the most persuasive thing this project could show.

**The word-collisions** — OPS, BOUNDARY, TRANSCENDENCE, FLEXIBILIZE and LADDER each mean two
different things in two different layers of the architecture. A sheet that merges them corrupts
the canon. 01_CANON_COMPLETE names all five.
