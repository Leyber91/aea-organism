# 05 — THE COMBINATION GRAMMAR

Reference sheet for concept art. Everything below is a thing that can be DRAWN: laws of
joining, not prose about design. Six doctrines recap first (already drawn), then the four
bodies of grammar that have never been drawn — the taught links, the mechanic pairings,
the composition rules, and the measured null results.

Marks used: `[MEASURED]` a real run produced it · `[BUILT]` enforced in running code ·
`[PLANNED]` designed, not built · `[DERIVED]` composed here from two canon rules, flagged
so it is never mistaken for a receipt.

---

## VISUAL LAW — restated, absolute, no exceptions

- **TWO INKS ONLY.** VOID ground `#050a10` deepening to `#0a1420`. STRUCTURE cold blue-gray
  `rgba(120,155,175, x)` at exactly five opacities: `.70` values and important lines · `.45`
  labels · `.28` secondary detail · `.14` hairlines and frames · `.08` faint rules and grids.
  LIFE amber at exactly two tiers: `#ffb000` HOT (working right now) · `#d4a24c` WARM
  (exists, earned, idle). Amber appears ONLY where something is alive, running, or earned.
  Forbidden absolutely: red, green, white, teal, purple, any third hue, any coloured glow
  that is not amber. One or two amber accents per sheet. A cold sheet is a correct sheet.
- **SIX GLYPH SHAPES ARE THE ONLY ICONS**: circle, pentagon, hexagon, triangle, square,
  diamond. No wrenches, gears, lightbulbs, arrows-as-decoration, or representational
  pictograms of any kind. Ideas are built from these six and abstract line-work.
- **FLAT TECHNICAL-BLUEPRINT RENDERING.** Matte, screen-printed, engineering-drawing
  discipline. No photoreal, no gloss, no chrome, no bloom, no lens flare, no god-rays, no
  drop shadows, no bevels. Line weights thin and deliberate — ~0.10 mm detail, ~0.18 mm
  structure. Surfaces read through line and value.
- **MONOSPACED TERMINAL TEXT AS TEXTURE.** Small codes, labels, readouts used as a surface
  material. Denser text means more evidence, never more ornament.
- **CORNER BRACKETS, NEVER BOXES.** Frames are four corner ticks. Edge ruler scales. A small
  diagram title block in one corner carrying ID, revision, scale, status.
- **NO EMOJI.**
- **NEVER draw the intelligence as a face, a figure, an eye, or a robot.** It is
  architecture, field, wire, and instrument. It has no body and no gaze.

**Ring geometry, canonical** (any map plate must obey): viewBox 1000 · core r70 ·
principles ring r150 HEXAGON · axes ring r250 PENTAGON · verbs/mechanics/ops ring r360
mixed (triangle · square · diamond) · seeds ring r470 CIRCLE.

## 3. THE FOUR MECHANIC-SEED PAIRINGS

Four seeds have a twin on the inner rail. The pairing is not decoration and not a
duplicate: the circle is the ORGAN, the square is that organ still running with no mission
open and nobody watching.

| square (r360) | circle (r470) | the seed's line | what the square adds |
|---|---|---|---|
| **CRYSTALLIZE** | seed.3 CRYSTALLIZE | freeze a repeated behaviour into a reusable tool | the toolkit grows BETWEEN ticks — no session, no operator, still growing |
| **FLEXIBILIZE** | seed.4 FLEXIBILIZE | kill a node mid-run — the route falls, the task completes | every live draw falls through, always, unattended |
| **SELF-VERSION** | seed.5 SELF-VERSION | a run writes a NEW skill; a later run uses it | reuse compounds across runs nobody ordered |
| **CEILING-DETECT** | seed.7 CEILING-DETECT | a quality gate flags the ceiling — escalate deeper | the gate meters every draw, always |

**Pairing laws.**
1. A mechanic is discovered WITH its seed, never separately. Same reveal, two glyphs.
2. A mechanic has NO composition station — it can never be a part in a construct. It is its
   seed's part left running. On any parts sheet, mechanics draw as an empty mount with a
   dash, never as a slottable block.
3. Canon nuance for CEILING-DETECT: it does not act. It recognizes exhaustion and FIRES the
   other three. Draw it as the only square whose link stubs point outward at the other
   squares — a trigger, not an actor.
4. Six seeds have no square. That asymmetry is information: draw the missing squares as
   absent, never as greyed placeholders.

## 4. COMPOSITION RULES

### 4.1 ZONE ARITHMETIC — how privacy combines, and which is strictest

Two different things share the word "zone" and must never be drawn as one instrument.

**RINGS ARE GEOLOGY** `[BUILT]`. A ring is a FACT about a provider, read from the catalog.
No brush ever repaints one. Four rings, strictest first:

```
LOCAL          the hearth — never leaves the machine, unlimited, slow
NO-TRAIN       hosted, contractually not trained on
TRAINS         hosted, trains on what it is given
KEYLESS        open socket, no key, public by construction
```

**ZONES ARE LAW** `[BUILT in the router]`. A zone classifies DATA, not a provider:
`sensitive` · `private` · `public`.

**The permission table** — which rings a zone may reach:

| data zone | permitted rings | state |
|---|---|---|
| sensitive | LOCAL only | `[BUILT]` — proven: a sensitive task routed local-only in a real run |
| private | LOCAL only, today | `[BUILT]` |
| private | LOCAL + NO-TRAIN, under the recall spec | `[PLANNED]` |
| public | LOCAL · NO-TRAIN · TRAINS · KEYLESS | `[BUILT]` |

**The arithmetic** (the rule the sheet exists to show):

```
zone(A ∘ B)  =  STRICTER( zone(A), zone(B) )
```

Combination NEVER loosens. There is no averaging, no majority, no override flag. A
construct's declared zone must be at least as strict as its strictest part; a spec that
declares looser fails validation and NAMES the violated clause rather than showing a
generic lock. Strictness order for the arithmetic: `sensitive > private > public`.

Corollaries worth drawing:
- One private part poisons the whole construct toward local — correctly. A single strict
  mount pulls the entire plate's ring band inward.
- The hearth is the floor every strict route lands on: local, unlimited, slow, always there.
- Nothing private ever belonged in a keyless socket — the keyless ring is a privacy fact
  before it is a capacity fact.
- A correctly-held strict route is a SCORING EVENT, not a refusal: draw the held route in
  warm amber, the leak as a hot-amber blink with the rule named in a chip. Never red.

**Drawing note.** Rings draw as ground curbs — four concentric bands under the plant row,
outermost = keyless. Zones draw as a clamp mark ON the wire, not as a colour of the wire.

### 4.2 THE JOIN TABLE — which port may meet which mount

`[DERIVED]` from two canon rules: every wiring edge must run between declared parts, and
every part declares its capability class. Port classes are capability classes.

**Port classes** (the only wire types in this world):

| class | carries | drawn as |
|---|---|---|
| POWER | a draw through the shared bus | double hairline, entering from beneath the plate |
| PROMPT | text in, text out — the ordinary edge | single hairline, left to right |
| GROUNDING | retrieved memory into a scaffold | hairline with one mid-line tick |
| SCORE | a falsifiable verdict on a run | short stub into a record block |
| CONSTRAINT | a zone clamp applied to another wire | a bracket sitting ON a wire |
| EXTERNAL | bytes leaving the machine | hairline that stops dead at the membrane |
| SPEECH | local voice out / local listen in | hairline terminating in an open half-circle |
| ARTIFACT | a real thing leaving the bench | terminal stub, no downstream mount |

**The parts, their mounts and their ports** (pool climbs by rung; `[PLANNED]` throughout —
the bench is the book's widest gap and nothing here has been built yet):

| part | rung | in-mounts | out-ports |
|---|---|---|---|
| **TAP** | 1 | POWER (from the bus) | POWER |
| **SCAFFOLD** | 1 | PROMPT · GROUNDING | PROMPT |
| **GOVERNOR** | 1 | PROMPT | PROMPT (rate-gated) |
| **LADDER** | 1 | PROMPT + POWER | PROMPT (first rod that answers) |
| **SCORER** | 1 | PROMPT (a result) | SCORE |
| **RECALL** | 2 | PROMPT (a query) | GROUNDING |
| **WALL** | 2 | any wire | same class, clamped |
| **COUNCIL** | 3 | PROMPT | PROMPT (n votes resolved to one) |
| **JOIN** | 3 | 2+ PROMPT | PROMPT |
| **ROUTER** | 3 | PROMPT | PROMPT × n (fan-out, depth-capped) |
| **PLAN** | 3 | a task | PROMPT + a committed axis-level tag |
| **RECORD BOOK** | 3 | SCORE + run stamp | terminal (bench memory) |
| **TOOL** | 4 | PROMPT | EXTERNAL |
| **MEMBRANE** | 4 | EXTERNAL | EXTERNAL (verdicted) |
| **SHIP SLOT** | 5 | PROMPT | ARTIFACT (terminal) |
| **SAVE-AS-PART** | 5 | a passing construct | a new named part |
| **VERSION SLOT** | 5 | construct v(n) | construct v(n+1), history kept |

Pool sizes as the ladder climbs: **5 → 7 → 12 → 14 → 17**.

**Legality rules — the sheet's actual content:**

1. **Class must match.** A GROUNDING port never enters a POWER mount. A mismatched join
   draws as two stubs that do not touch, with the class names in `.45` beside each.
2. **Both ends declared.** An edge to a part not in the spec fails — the failure is drawn as
   a severed wire with the clause named, never a generic lock.
3. **Unlocked and bench-legal.** A part must be in the current rung's pool AND be
   bench-legal. Substrate is never bench-legal (see 4.3).
4. **A WALL may clamp any wire.** A clamped wire may only enter a mount whose permitted ring
   set contains the payload's zone (4.1).
5. **EXTERNAL may only meet the membrane.** Never part-to-part. Tools do not touch the world
   directly, ever.
6. **ARTIFACT is terminal.** Nothing mounts downstream of the ship slot. The last wire on
   any plate goes off the edge of the plate.
7. **The trace-wire is chrome, not a part.** Every edge draws its own live route during a
   run, and a failing link surfaces AT the link that failed, mid-run — never at the end.
8. **No part ever names a model.** A part requests a TIER (reflex · bulk · deep); the ladder
   resolves tier to a real rod at draw time from live fitness. Model names never appear on
   a construct plate.

### 4.3 THE GATE LAW — the one rule that governs the frame itself

**The gate wraps every construct and can never be a part inside one.**

The watcher, the trust ledger, the meter, the pulse, the trace ledger and the power bus are
day-0 law of the entity. They carry no unlock act, they appear in no pool, and they are
declared bench-illegal in the registry. A construct cannot slot the gate; the gate is what
the construct runs INSIDE.

Consequences that must be drawn correctly:
- On a construct plate, the gate is **the bracket frame**, not a block on the wire. It is the
  corner brackets themselves — which is why this world never draws closed boxes.
- The gate can HOLD a construct's output. A held run is a legitimate outcome and draws in
  warm amber with the verdict text set in mono beside it, not as damage.
- Only the PLAYER'S control surfaces unlock over the campaign. The entity's laws never
  unlock — there is no act in which governance is granted.
- A construct spec can never out-rank the ledger. Outbound send stays forbidden at the
  charter level regardless of what any spec declares.

### 4.4 THE POINTER-SET LAW — what a construct actually is

A construct is a POINTER SET, not a program: part ids into the registry, tier requests into
the ladder, wiring edges, per-part policy, one zone. Tiny, diffable, and meaningless without
the registry it references. Validation is a pure re-walk: every part registered, every part
unlocked, every part bench-legal, every edge between declared parts, every policy key inside
the part's declared surface, the construct's zone at least as strict as its strictest part.
Running it walks the wiring and fires each part's REAL entry point — metered, gated, traced.
There is no second execution engine.

**Drawing note.** A construct plate is therefore a schematic and a manifest at once: the
wiring diagram above, the pointer list below in mono, and the zone band down one edge.

## 5. MEASURED NULL RESULTS — negative findings, drawn as first-class evidence

No sheet in this world has ever shown a negative result. Every entry here is a real
measurement of something that DID NOT work. They are as citable as the doctrines and are
drawn with the same plate discipline — the difference is that a null plate carries NO amber
except on the word that names the null.

| id | THE NULL | what was measured | why it matters |
|---|---|---|---|
| N1 | **SAME-MODEL ENSEMBLES DO NOT RESCUE** | on a hard/unreliable task, ensembles of one model did not rescue it; the diverse-model vote did — net +3, 0 damage | the intuition "more calls = more reliability" is false; the axis that pays is model identity |
| N2 | **TEMPERATURE IS NOT DIVERSITY** | varying temperature across a council did not produce the rescue; varying the MODEL did | sampling noise is not a second opinion. The most commonly assumed cheap fix is measured worthless |
| N3 | **A COUNCIL HURTS AN EASY TASK** | council overhead damaged easy-task accuracy in the same experiment series | ensembling is not free and not neutral. It is a cost paid for a specific regime |
| N4 | **A LONE VERIFIER CAN BE WRONG ALONE** | verifier error analysis: one watcher, same-model, no schema, fails silently | the gate survives on strict schema plus a DIFFERENT model — heterogeneity, not authority |
| N5 | **A BENCHMARK PASS IS NOT A FITNESS PASS** | a model scored 4/4 on the earlier report, then timed out in a real production run and shipped a hole in the delivered artifact | the founding failure of the whole fitness system. Score against the jobs you actually run |
| N6 | **A PERFECT SCORE DOES NOT SURVIVE A SWEEP** | one sweep, 2026-07-19: usable pool 44 → 29; perfect scorers 7 → 2 | a third of the armory rusted with zero design intervention. Rot is the world, not a mechanic |
| N7 | **TOOL NAMES GET INVENTED** | 25 of 149 emitted actions (16.8%) invented a tool name from the hypothesis type; the parser-side validator caught every one | the measured reason strict schemas exist. Draw it as the star exhibit of the governance plate |
| N8 | **MOST TRIGGERS NEVER FIRED** | of 8 trigger modes over a sustained run, 3 fired (162 · 96 · 16 firings); the other 5 had preconditions unmet | a designed mechanism that never fires is a real, publishable result. Do not draw eight lit nodes |
| N9 | **THE FIRST THOUGHT WAS REFUSED** | the entity's first recorded reflection was HELD by its own watcher and never persisted; the first KEPT thought landed 134 seconds later | the first thing this mind ever kept was one its watcher made it earn |
| N10 | **PERMANENT COOLING DECAYS TO THE FLOOR** | the original cooling rule was a permanent tombstone — nothing could reset a failure count because a cooled rod was never drawn again; the pool decayed monotonically to the local floor | fixed by a 15-minute retry window. A punishment with no path back is a slow death, measured |
| N11 | **THREE OF FIVE RESEARCH TRACKS SURVIVED** | 122 claims extracted, top 25 adversarially verified: 21 confirmed, 4 refuted, 0 unverified; one whole track produced ZERO verifiable claims | refuted claims are design law too. The empty track is drawn as an empty bracket with its name |
| N12 | **NOTHING HAS BEEN COMPOSED YET** | across 29 codex elements, the composition station is reached by 0 | the honest widest gap. Drawn as 29 empty mounts and one lit counter reading 0 |

**Drawing notes for null plates.** Same bracket frame, same title block, same ruler edge as
a doctrine plate. The distinguishing marks: the plate face carries a single diagonal
hairline at `.14` running corner to corner behind the content; the result figure sits in
structure `.70`, not amber; exactly one word may be amber — the verb of the null (DID NOT
RESCUE / HURTS / INVENTED / REFUSED). A null plate must never look like a warning: no red,
no hazard chevrons, no crossed-out glyphs.
