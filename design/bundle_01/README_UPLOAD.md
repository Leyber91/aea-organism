# BUNDLE 01 — the upload set for concept generation

Ten files. Upload all ten in one conversation, then paste the megaprompt block from
`00_MEGAPROMPT.md` and swap only its final CATEGORY line per image.

## What each file is for

| file | why the generator needs it |
|---|---|
| 00_MEGAPROMPT.md | THE INSTRUCTION — the block to paste + the 10 category lines |
| 01_VISUAL_LAW_signature.md | the two-ink religion, the four owned motifs, the eight bans |
| 02_VISUAL_DIRECTION.md | modern-aesthetics research; the 2000s tells to avoid |
| 03_WORLD.md | the field, the foundry, the districts, real coordinates |
| 04_STORY.md | the premise, the antagonist (fog), the moral centre |
| 05_VOICE_narrative.md | the terminal voice — for captions and inscriptions |
| 06_GLOSSARY.md | every term with its real referent — vocabulary for labels |
| 07_PATHS_and_ladder.md | the six-rung assistant ladder and the four stations |
| 08_AEA_MATRIX.md | all 29 elements crossed with every game dimension |
| 09_AEA_ELEMENTS_data.js | the raw canon: 29 elements + 6 measured doctrines |

## Opening line to use with the upload

"These ten files are the design canon for a game called THE PROBE. Read them all before
generating anything. Then follow the megaprompt block in 00_MEGAPROMPT.md exactly: it defines
an ATLAS SHEET format and a visual law that is absolute. I will give you one CATEGORY per
message. Never use a third colour, never draw a face or a robot, never render photoreal."

## Boundary note (checked 2026-07-21)

These ten were curated and privacy-scanned before copying: no employer names, no personal
addresses, no local paths, no compensation or work-arrangement context. Deliberately EXCLUDED
from this bundle: the production log, the prototype ladder, the coverage audit, the Phase B
chapter and the engineering chapters — they carry working context that has no bearing on
image generation and does not belong on an external service.

Design docs remain Luis's IP; uploading grants the service its usual training/retention terms.
Nothing here is secret, but nothing here is disposable either.
